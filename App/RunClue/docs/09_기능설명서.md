## 3. 미션(클루) 모듈

### 3.1 클루 CRUD
| 기능 | API 메서드 | 설명 |
|------|-----------|------|
| 클루 생성 | `ClueService.createClue()` | 제목, 설명, 카테고리, 설정, 보상 |
| 클루 수정 | `ClueService.updateClue()` | 상태 변경 포함 |
| 클루 삭제 | `ClueService.deleteClue()` | soft delete (suspended) |
| 클루 조회 | `ClueService.getClueById()` | 스텝 포함 |
| 트렌딩 | `ClueService.getTrendingClues()` | view_count + like_count 정렬 |
| 근처 클루 | `ClueService.getNearbyClues()` | PostGIS `nearby_clues()` RPC |
| 검색 | `ClueService.searchClues()` | title/description ilike 검색 |
| 좋아요 | `ClueService.toggleLike()` | likes 테이블 toggle |

### 3.2 스텝 관리
| 기능 | API 메서드 | 설명 |
|------|-----------|------|
| 스텝 CRUD | `StepService.createStep()` / `updateStep()` / `deleteStep()` | 타입별 필드 포함 |
| 순서 변경 | `StepService.reorderSteps()` | batch update order_index |

### 3.3 스텝 타입 상세

| 타입 | Evidence 형식 | 검증 방식 | 타임아웃 |
|------|-------------|----------|---------|
| CHECKPOINT | GPS 좌표 | 자동 (Haversine 50m 이내) | 없음 |
| SNAPSHOT | 사진 파일 | 수동 (호스트 승인) | 10분 → 자동 승인 |
| QUEST | 텍스트 입력 | 자동(정답비교) 또는 수동 | 10분 (수동 시) |
| OX_QUIZ | O/X 선택 | 자동 (정답 비교) | 없음 |
| LIST | 체크리스트 완료 | 자동 (전체 항목 체크) | 없음 |

## 4. 검증 모듈

### 4.1 검증 오케스트레이터
| 구분 | 흐름 | 구현 |
|------|------|------|
| 자동 검증 | Evidence 제출 → 즉시 판정 → auto_approved/auto_rejected | `ValidationOrchestrator` |
| 수동 검증 | Evidence 제출 → pending → 호스트 승인/반려 | `HostDashboardScreen` |
| 지연 검증 | Evidence 제출 → pending → 10분 타임아웃 → auto_approved | Edge Function |

### 4.2 자동 검증 알고리즘
| 검증 | 알고리즘 | 구현 |
|------|---------|------|
| GPS 근접 | Haversine 거리 ≤ radius_meters | `EvidenceService.autoValidateCheckpoint()` |
| 퀴즈 정답 | trim + lowercase 비교 | `EvidenceService.autoValidateQuiz()` |
| 체크리스트 | requiredItems.every() | `EvidenceService.autoValidateChecklist()` |

## 5. 실시간 모듈

| 채널 | 이벤트 | 용도 |

| 실시간 알림 | `NotificationService` | 알림 INSERT 감지 |

## 8. 기타 기능

### 8.1 온보딩
- 3페이지 슬라이드 (미션 만들기 → 실시간 참여 → 완료/공유)
- SharedPreferences로 1회만 표시

### 8.2 QR 스캐너
- `QrScannerWidget` — mobile_scanner 패키지
- CHECKPOINT 스텝의 대체 검증 방식

### 8.3 신고
- `ReportService.submitReport()` — 7가지 사유
- `ReportDialog` — UI 다이얼로그

### 8.4 하이라이트 릴
- `HighlightReelScreen` — SNAPSHOT 증거 사진 자동 슬라이드쇼
- 3초 자동 전환 + 일시정지 + 공유

### 8.5 축하 애니메이션
- `CelebrationOverlay` — 컨페티 파티클 + 스케일 바운스
- 미션 완료 시 3초 재생

## 9. 데이터베이스 스키마 (14 테이블)

| 테이블 | 용도 | RLS |
|--------|------|-----|
| profiles | 사용자 프로필 | 본인만 수정 |
| clues | 미션 정보 | creator만 수정, 공개 미션 전체 조회 |
| steps | 미션 스텝 | creator만 수정 |
| participations | 참여 기록 | 본인만 조회/수정 |
| evidences | 인증 증거 | 본인 INSERT, creator 조회/검증 |
| clans | 클랜(팀) | leader만 수정 |
| clan_members | 클랜 멤버 | 본인/leader 관리 |
| rewards | 보상 기록 | 본인만 조회 |
| reports | 신고 | 본인 INSERT, admin 관리 |
| notifications | 알림 | 본인만 조회 |
| community_posts | 커뮤니티 게시글 | 전체 조회, 본인만 수정 |
| post_comments | 댓글 | 전체 조회, 본인만 수정 |
| likes | 좋아요 | 전체 조회, 본인만 관리 |
| blocks | 차단 | 본인만 관리 |
