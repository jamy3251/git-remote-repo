# 04. PRD (Product Requirements Document)

> RunClue - 참여형 미션 플랫폼 제품 요구사항 문서
>
> 문서 상태: 내부 검토용 초안 | 버전: 0.1

---

## 1. 한 줄 요약

**RunClue는 누구나 "Clue(미션)"를 만들고 참여할 수 있는 오프라인-온라인 연결형 참여 미션 플랫폼이다.**

---

## 2. 문제 / 기회

### 2.1 해결하려는 문제

| 문제 | 현재 상황 | RunClue의 접근 |
|------|-----------|----------------|
| 그룹 활동 기획의 높은 진입장벽 | MT, 워크샵, 수학여행 등 팀 게임 기획에 많은 시간과 노력 필요. 매번 수작업으로 진행 | 템플릿 기반 Clue 생성으로 누구나 5분 내 미션 기획 가능 |
| 오프라인 활동의 디지털 검증 부재 | 보물찾기, 출석체크 등 오프라인 활동의 증거 수집/검증이 비체계적 | GPS, 사진, QR 등 다양한 자동 검증 지원 |
| 참여형 콘텐츠 플랫폼 부재 | 기존 플랫폼은 소비형(시청/읽기) 중심. 능동적 참여 구조 부족 | Creator-Participant 구조로 능동적 참여 유도 |
| 교육 현장의 디지털 도구 한계 | 출석체크, 현장 평가 등 교육 활동에 적합한 앱 부족 | 교육 특화 Step 타입 + 최소 수집 원칙 |
| 소상공인 홍보 수단의 한계 | 지역 매장 홍보를 위한 저비용 참여형 마케팅 도구 부족 | 방문 미션 기반 프로모션 Clue |

### 2.2 시장 기회

- **MZ세대의 체험형 활동 수요 증가**: 방탈출, 보물찾기 등 참여형 오프라인 활동 시장 성장
- **교육 분야 에듀테크 확산**: 현장 학습, 체험 활동의 디지털화 트렌드
- **크리에이터 이코노미 확대**: 일반 사용자가 콘텐츠를 생산하는 UGC 플랫폼 성장
- **스트리머 인터랙티브 콘텐츠 수요**: 시청자 참여형 방송 콘텐츠에 대한 수요 증가
- **O2O(Online-to-Offline) 마케팅**: 오프라인 매장 방문을 유도하는 디지털 마케팅 성장

## 3. 목표 / 비목표

### 3.1 목표

| # | 목표 | 측정 방법 |
|---|------|-----------|
| G1 | 누구나 쉽게 미션을 만들고 공유할 수 있는 Creator 경험 제공 | Clue 생성 완료율 70% 이상 |
| G2 | 오프라인 활동의 디지털 검증 및 기록 자동화 | 자동 검증률 70% 이상 |
| G3 | 안전하고 신뢰할 수 있는 참여 환경 구축 | 신고 처리 시간 24시간 이내 |
| G4 | 다양한 시나리오에 적용 가능한 확장 가능 플랫폼 | Step 타입 5종 이상 지원 |
| G5 | 참여자-Creator 간 선순환 생태계 구축 | Creator 재생성률 30% 이상 |
| G6 | 그룹 활동(MT, 워크샵) 시장의 대표 도구화 | 월간 그룹 Clue 생성 500건 (출시 6개월 후) |

### 3.2 비목표

| # | 비목표 | 이유 |
|---|--------|------|
| NG1 | 풀 게임 엔진이 되는 것 | RunClue는 미션/이벤트 플랫폼이지 게임 개발 도구가 아님 |
| NG2 | SNS/소셜 미디어를 대체하는 것 | 커뮤니티 기능은 미션 활동 보조 수단 |
| NG3 | 전문 교육 평가 시스템 | 교육 보조 도구이지 LMS 대체재가 아님 |
| NG4 | 배달/심부름 대행 플랫폼 | 생활형 Clue는 보조 기능이며 전문 대행 서비스가 아님 |
| NG5 | 실시간 위치 추적 앱 | 위치는 검증 수단이며 실시간 추적이 목적이 아님 |
| NG6 | 글로벌 동시 출시 | 초기에는 한국 시장에 집중 |

## 6. MVP / P1 / P2 범위

### 6.1 MVP (최소 실행 가능 제품)

| # | 기능 | 설명 | 우선순위 근거 |
|---|------|------|---------------|
| MVP-01 | 회원가입/로그인 | 소셜 로그인(카카오, 네이버, 구글) + 이메일 | 서비스 진입 필수 |
| MVP-02 | Clue 생성 (기본) | 제목, 설명, 카테고리, 참여 조건, 시간 설정 | 핵심 Creator 기능 |
| MVP-03 | CHECKPOINT Step | GPS 기반 위치 도달 검증 | 오프라인 활동 핵심 |
| MVP-04 | SNAPSHOT Step | 사진 촬영 증거 제출 | 시각적 검증 핵심 |
| MVP-05 | QUEST Step | 텍스트 미션 수행 및 답변 제출 | 범용 미션 타입 |
| MVP-06 | OX_QUIZ Step | O/X 퀴즈 출제 및 자동 채점 | 퀴즈 시나리오 핵심 |
| MVP-07 | LIST Step | 체크리스트 항목 완료 확인 | 교육/활동 관리 |
| MVP-08 | 자동 검증 | GPS 일치, QR 스캔, 정답 매칭 | 운영 효율 핵심 |
| MVP-09 | 수동 검증 | Creator의 Evidence 승인/반려 | 자동 검증 보완 |
| MVP-10 | 내 주변 Clue 탐색 | 지도 기반 근처 Clue 목록 | 참여자 진입점 |
| MVP-11 | Clue 참여 및 진행 | Step별 순차 진행, 진행률 표시 | 참여자 핵심 경험 |
| MVP-12 | 기본 보상 | 포인트 적립, 배지 부여 | 참여 동기 부여 |
| MVP-13 | 결과/랭킹 화면 | Clue 완료 후 순위 및 결과 표시 | 경쟁 요소 |
| MVP-14 | 기본 프로필 | 프로필 관리, 참여 이력, 획득 배지 | 사용자 정체성 |
| MVP-15 | 푸시 알림 | Clue 시작/종료, 검증 결과 알림 | 재참여 유도 |
| MVP-16 | 관리자 콘솔 (기본) | Clue 승인/반려, 신고 확인 | 운영 필수 |
| MVP-17 | 신고 기능 | Clue/사용자/Evidence 신고 | 안전 필수 |
| MVP-18 | QR 코드 검증 | QR 스캔을 통한 위치/아이템 확인 | CHECKPOINT 대체 수단 |
| MVP-19 | Clue 공유 (딥링크) | URL 공유로 Clue 참여 유도 | 바이럴 성장 |
| MVP-20 | 온보딩 튜토리얼 | 첫 사용자 가이드 | 리텐션 |

## 7. KPI

| Creator 재생성률 | Clue를 2개 이상 만든 Creator 비율 | 30% 이상 | 월간 |
| 평균 참여 인원 | Clue당 평균 참여자 수 | 8명 이상 | 주간 |
| 자동 검증률 | 전체 Evidence 중 자동 검증 비율 | 70% 이상 | 주간 |
| 신고 처리 시간 | 신고 접수 후 1차 처리까지 평균 시간 | 24시간 이내 | 주간 |
| NPS | 순추천지수 | 30 이상 | 분기 |
| 앱 크래시율 | 세션 대비 크래시 비율 | 0.5% 이하 | 일간 |
| 평균 세션 시간 | 1회 앱 사용 평균 시간 | 15분 이상 | 주간 |

## 부록: 용어 정의

| 용어 | 정의 |
|------|------|
| Clue | 하나의 게임/이벤트/요청 단위. Creator가 생성하고 Participant가 참여 |
| Step | Clue를 구성하는 개별 단계. 타입에 따라 다른 검증 방식 적용 |
| Evidence | Step 수행의 증거. 사진, 위치, 영상, QR, 텍스트 답변 등 |
| Validation | Evidence에 대한 검증. 자동(auto), 지연(delayed), 수동(manual) |
| Reward | Clue 완료 보상. 포인트, 배지, 쿠폰, 상금, 추첨권 |
| Creator | Clue를 생성하는 사용자 |
| Participant | Clue에 참여하는 사용자 |
| Clan | 사용자들의 팀/그룹 단위 |
