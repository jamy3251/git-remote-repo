# RunClue 사용설명서

> **버전**: v1.0 | **최종 수정**: 2026.04 | **대상**: 일반 사용자 (탐험가, 크리에이터, 사장님)

---

## 1. RunClue란?

RunClue(런클루)는 **위치기반 게임 미션 마켓플레이스**입니다.

- **탐험가**: 실제 오프라인 공간을 이동하며 미션을 수행하고 보상을 받습니다
- **크리에이터**: 미션(클루)을 직접 설계하고 수익을 창출합니다
- **사장님**: 미션을 통해 매장에 고객을 유입시킵니다

슬로건: **"뛰자, 풀자, 벌자."**

---

## 2. 시작하기

### 2.1 앱 설치
- Google Play Store에서 "RunClue" 검색 후 설치
- iOS App Store 지원 예정 (2026년 하반기)

### 2.2 회원가입 / 로그인
1. 앱을 실행하면 로그인 화면이 나타납니다
2. 로그인 방법을 선택합니다:
   - **카카오로 시작하기** (추천) — 카카오 계정으로 즉시 가입
   - **네이버로 시작하기** — 네이버 계정으로 가입
   - **Google로 시작하기** — Google 계정으로 가입
   - **이메일로 로그인** — 이메일/비밀번호 직접 입력
3. 최초 가입 시 닉네임을 설정합니다
4. 위치 권한을 허용합니다 (미션 참여에 필요)

### 2.3 딥링크로 참여 (비회원)
- 친구가 공유한 링크를 클릭하면 **회원가입 없이** 즉시 미션에 참여할 수 있습니다
- 닉네임만 입력하면 바로 시작

## 3. 홈 화면 (HOME)

### 3.1 플랫폼 스탯 바
- 상단에 전체 참여자 수, 누적 수익, 활성 미션 수가 실시간으로 표시됩니다

### 3.2 역할 탭
- **탐험가**: 참여 가능한 미션 목록
- **크리에이터**: 내가 만든 미션 관리
- **사장님**: 매장 홍보 미션 등록

### 3.3 LIVE 히어로 카드
- 현재 진행 중인 실시간 미션이 표시됩니다
- LIVE 배지 + 남은 시간 + 참여자 수 + 상금 확인
- "참여 →" 버튼으로 즉시 참여

### 3.4 미션 카드 리스트
- 인기 미션, 근처 미션, 카테고리별 미션을 탐색합니다
- 카드에 표시되는 정보: 미션명, 위치, 참여자 수, 상금, 진행도

## 4. 미션 참여하기 (탐험가)

### 4.1 미션 찾기
1. HOME 탭에서 미션 카드를 탭합니다
2. 또는 검색 아이콘을 탭하여 키워드/위치/카테고리로 검색합니다

### 4.2 미션 상세 확인
- 미션 제목, 설명, 카테고리
- 스텝 수, 예상 소요 시간
- 참여 조건 (인원 제한, 시간 제한)
- 보상 정보 (포인트, 배지, 쿠폰, 상금)

### 4.3 미션 진행
1. "참여하기" 버튼을 탭합니다
2. 스텝을 순서대로 수행합니다:

| 스텝 타입 | 수행 방법 | 검증 방식 |
|----------|----------|----------|
| **체크포인트** | 지정된 위치에 도착 | GPS 자동 확인 (50m 이내) |
| **스냅샷** | 사진 촬영하여 제출 | 호스트 수동 확인 (10분 내 자동 승인) |
| **퀘스트** | 텍스트 답변 입력 | 자동/수동 확인 |
| **OX 퀴즈** | O 또는 X 선택 | 즉시 자동 채점 |
| **리스트** | 체크리스트 항목 완료 | 전체 항목 체크 시 자동 완료 |

3. 각 스텝 완료 시 실시간 피드에 표시됩니다
4. 모든 스텝 완료 시 **승리 카드**가 생성됩니다

### 4.4 실시간 미션 맵
- 미션 진행 중 지도에서 참여자들의 위치를 실시간으로 확인할 수 있습니다
- 체크포인트 위치가 핀으로 표시됩니다

### 4.5 미션 완료
- 축하 애니메이션이 재생됩니다
- 승리 카드가 자동 생성됩니다 (순위, 점수, 소요시간)
- 카카오톡/인스타그램으로 공유할 수 있습니다
- 하이라이트 릴에서 인증 사진을 슬라이드쇼로 확인할 수 있습니다

## 5. 미션 만들기 (크리에이터)

### 5.1 클루 만들기
1. 하단 **제작** 탭 또는 노란색 **+** FAB 버튼을 탭합니다
2. 6단계 위저드를 따라 미션을 만듭니다:

**Step 1 — 기본 정보**
- 미션 제목, 설명 입력
- 카테고리 선택 (어드벤처, 퀴즈, 교육, 생활도움, 프로모션, 워크숍)
- 썸네일 이미지 선택

**Step 2 — 설정**
- 공개/비공개 설정
- 최대 참여자 수
- 시작/종료 시간
- 참여자 제한시간 (분)

**Step 3 — 스텝 구성**
- "스텝 추가" 버튼으로 미션 단계를 추가합니다
- 5가지 스텝 타입 중 선택:
  - **체크포인트**: 지도에서 목표 위치 + 반경 설정
  - **스냅샷**: 사진 촬영 미션 (참고 이미지 첨부 가능)
  - **퀘스트**: 질문 + 정답 + 답변 유형 (정확히/포함/자유)
  - **OX 퀴즈**: 정답(O/X) + 해설 + 제한시간
  - **리스트**: 체크리스트 항목 추가
- 드래그로 스텝 순서 변경
- 스텝별 편집/삭제 가능

**Step 4 — 보상 설정**
- 보상 유형: 포인트, 배지, 쿠폰, 없음
- 보상 값 설정

**Step 5 — 미리보기 & 제출**
- 미션 정보 요약 확인
- "임시저장" 또는 "승인 요청" 선택

### 5.2 호스트 대시보드
- 미션이 활성화되면 호스트 대시보드에서 관리합니다
- **실시간 탭**: 참여자 인증 제출/완료 이벤트 실시간 확인
- **승인 대기 탭**: 스냅샷/퀘스트 인증을 승인/반려
- **순위 탭**: 참여자 순위 확인

### 5.3 미션 공유
- 미션 상세 화면에서 공유 아이콘을 탭합니다
- 카카오톡, 시스템 공유 시트로 링크를 전송합니다
- 비회원도 링크로 즉시 참여 가능

## 7. 내 정보 (MY)

### 7.1 프로필
- 닉네임, 프로필 사진, 소개글 설정
- 참여 통계: 참여한 클루 수, 완료한 클루 수, 총 포인트

### 7.2 배지 컬렉션
- 획득한 배지를 확인합니다
- 등급: 일반(회색) → 희귀(파랑) → 영웅(보라) → 전설(금색)

### 7.3 설정
- 알림 설정 (푸시 알림 ON/OFF)
- 개인정보 관리
- 차단 사용자 관리
- 이용약관 / 개인정보처리방침

## 9. 신고하기

부적절한 콘텐츠나 사용자를 발견하면:
1. 해당 콘텐츠/사용자의 더보기(⋯) 메뉴를 탭합니다
2. "신고하기"를 선택합니다
3. 신고 사유를 선택합니다 (부적절, 스팸, 사기, 안전위협, 괴롭힘, 저작권, 기타)
4. 상세 설명을 입력합니다 (선택)
5. "신고" 버튼을 탭합니다

## 11. 자주 묻는 질문 (FAQ)

**Q: 미션 참여 중 인터넷이 끊기면?**
A: 인증 사진은 로컬에 임시 저장되며, 네트워크 복구 시 자동으로 재전송됩니다.

**Q: 스냅샷 인증이 10분 넘게 대기 중이면?**
A: 호스트가 10분 내에 확인하지 않으면 자동으로 승인됩니다.

**Q: 비회원으로 참여하면 포인트를 받을 수 있나요?**
A: 미션 완료 후 정식 가입하면 포인트가 이전됩니다.

**Q: 미션을 중간에 그만둘 수 있나요?**
A: 네, 언제든 "포기" 버튼으로 미션을 중단할 수 있습니다.
