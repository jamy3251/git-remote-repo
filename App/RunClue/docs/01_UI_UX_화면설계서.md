# RunClue UI/UX 화면설계서

> 본 문서는 RunClue 플랫폼의 정보구조, 사용자 여정, 화면 상세, 권한 설계, 신뢰 UX, 디자인 시스템을 정의한다.
> 용어 정의는 `00_문서개요.md`를 따른다.

---

## 1. UX 원칙

RunClue의 모든 화면 설계는 아래 7가지 원칙을 기반으로 한다.

| 번호 | 원칙 | 설명 |
|------|------|------|
| UX-1 | **즉시 이해 (Instant Clarity)** | 화면에 진입한 순간 무엇을 해야 하는지 3초 이내에 파악할 수 있어야 한다. CTA 버튼은 화면당 1개를 원칙으로 하고, 보조 액션은 시각적으로 구분한다. |
| UX-2 | **최소 입력 (Minimal Input)** | 참여자에게 텍스트 입력을 최소화한다. 사진 촬영, 위치 자동 인식, QR 스캔, 선택형 UI를 우선 사용한다. |
| UX-3 | **실시간 피드백 (Real-time Feedback)** | 증거 제출, 검증 진행, 보상 지급 등 모든 상태 변화에 대해 즉각적인 시각/진동/사운드 피드백을 제공한다. |
| UX-4 | **안전한 실패 (Safe Failure)** | 네트워크 단절, 권한 미허용, 시간 초과 등 실패 상황에서 데이터 유실 없이 복구 경로를 안내한다. 증거는 로컬에 임시 저장된다. |
| UX-5 | **점진적 복잡성 (Progressive Complexity)** | Clue 제작 시 기본 모드(템플릿 기반)와 고급 모드(커스텀 설계)를 분리하여, 초보 제작자도 5분 이내에 첫 Clue를 만들 수 있도록 한다. |
| UX-6 | **투명한 신뢰 (Transparent Trust)** | 증거 공개 범위, 보관 기간, 수수료, 정산 시점을 사전에 명확히 고지하여 참여자와 제작자 모두의 신뢰를 확보한다. |
| UX-7 | **포용적 접근 (Inclusive Access)** | 색각 이상 사용자를 고려한 색상 외 보조 표시(아이콘, 패턴), 최소 터치 영역 44x44dp, 스크린 리더 호환 라벨을 적용한다. |

## 2. 정보구조(IA)와 탭 구조

### 2.1 메인 탭 구조

앱 하단에 5개의 메인 탭을 배치한다.

```
[탐색]     [참여]     [제작]     [소통]     [내정보]
 Explore   Join      Create    Community  My
```

| 탭 | 아이콘 | 역할 | 주요 하위 화면 |
|----|--------|------|----------------|
| 탐색 | 나침반 | Clue 발견, 검색, 필터, 지도 탐색 | 홈 피드, 카테고리별 목록, 지도 뷰, 검색 결과, 이벤트/주간 랭킹 |
| 참여 | 플레이 | 진행 중/완료된 Clue 관리 | 참여 중 목록, 진행 현황, 증거 제출, 결과 확인 |
| 제작 | 플러스 | Clue 생성 및 관리 | 템플릿 선택, Step 편집, 검증 설정, 보상 설정, 승인 상태 |
| 소통 | 말풍선 | 커뮤니티, 클랜, 게시판, 알림 | 전체 게시판, 클랜 목록, 클랜 채팅, 알림 센터 |
| 내정보 | 사람 | 프로필, 보상 내역, 설정 | 프로필, 뱃지 컬렉션, 포인트/쿠폰, 주간 리포트, 설정 |

## 3. 사용자 여정 (User Journey)

### 3.1 온보딩 여정

```
앱 설치 -> 스플래시 -> 온보딩 슬라이드(3장)
-> 회원가입 (소셜/이메일) -> 관심사 선택 -> 위치 권한 요청
-> 홈 피드 진입
```

| 단계 | 화면 | 핵심 액션 | 이탈 방지 |
|------|------|-----------|-----------|
| 1. 첫 진입 | 스플래시 | 앱 로딩 | 2초 이내 전환 |
| 2. 가치 전달 | 온보딩 슬라이드 | 좌우 스와이프, 건너뛰기 | 3장 이내, 건너뛰기 항상 노출 |
| 3. 가입 | 회원가입 | 소셜 로그인(카카오/네이버/애플/구글) 또는 이메일 | 소셜 로그인 최상단 배치 |
| 4. 개인화 | 관심사 선택 | 카테고리 3개 이상 선택 | "나중에 선택" 옵션 제공 |
| 5. 권한 | 위치 권한 | 시스템 권한 팝업 | 권한 필요 사유 사전 설명 화면 |
| 6. 완료 | 홈 피드 | 첫 추천 Clue 노출 | 튜토리얼 Clue 최상단 고정 |

### 3.2 탐색 여정

```
홈 피드 진입 -> 이벤트 배너/추천 Clue 확인 -> 카테고리 필터 또는 검색
-> 주간 랭킹 확인 -> Clue 카드 탭 -> Clue 상세 확인
-> 주변 Clue 지도 탐색
```

| 단계 | 설명 | 핵심 요소 |
|------|------|-----------|
| 피드 스크롤 | 추천/인기/신규/근처 Clue를 섹션별로 노출 | 이벤트 배너(상단), 추천 Clue 카드, "더 보기" 링크 |
| 카테고리 필터 | 오프라인/온라인/생활도움/교육/프로모션 필터칩 | 다중 선택 가능, 선택 시 실시간 목록 갱신 |
| 주간 랭킹 | 이번 주 인기 Clue, 활발한 참여자, 우수 제작자 | 탭 전환(Clue/참여자/제작자), 순위 카드 |
| 검색 | 키워드, 태그, 위치 기반 검색 | 자동완성, 최근 검색어, 인기 검색어 |
| 지도 탐색 | 내 위치 중심으로 주변 Clue 핀 표시 | 클러스터링, 핀 탭 시 미니 카드, 필터 연동 |
| 상세 확인 | Clue 정보, Step 미리보기, 참여 조건, 난이도, 예상 소요시간 | "참여하기" CTA, 공유, 찜하기 |

### 3.3 참여 여정

```
Clue 상세 -> "참여하기" 탭 -> 참여 조건 확인 (인원/기간/비용)
-> 참여 확정 -> 진행 화면 진입
```

| 단계 | 조건 | 처리 |
|------|------|------|
| 참여 신청 | 로그인 상태 확인 | 비로그인 시 로그인 화면으로 이동 |
| 조건 확인 | 인원 제한, 참여 기간, 참가비 | 마감 시 "마감" 표시, 참가비 있는 경우 결제 플로우 연결 |
| 팀 구성 | 클랜 단위 참여 여부 | 개인 참여 / 클랜 선택 화면 분기 |
| 진입 | 첫 Step 자동 로드 | 진행률 바 0%에서 시작, 환영 메시지 |

### 3.4 진행 여정

```
Step 확인 -> 미션 수행 -> 증거 수집 (사진/위치/QR/답변/텍스트/영상)
-> 증거 제출 -> 다음 Step 이동 -> 반복 -> 전체 완료
```

| Step 유형 | 참여자 행동 | 증거 수집 방식 | 자동 다음 이동 |
|-----------|------------|----------------|----------------|
| CHECKPOINT | 지정 위치로 이동 | GPS 자동 감지 또는 QR 스캔 | 범위 내 도달 시 자동 완료 |
| SNAPSHOT | 카메라로 촬영 | 카메라 실행, 촬영 후 미리보기 | 제출 완료 후 이동 |
| QUEST | 텍스트 미션 수행 | 텍스트 입력 또는 파일 첨부 | 제출 완료 후 이동 |
| OX_QUIZ | 문제 읽고 답변 선택 | O/X 버튼 또는 객관식 선택 | 정답 시 즉시 이동 (오답 시 재시도/실패 분기) |
| LIST | 항목별 수집/체크 | 체크리스트 UI, 항목별 증거 | 전체 항목 완료 시 이동 |
| BOARD | 게시글 작성 | 텍스트 에디터, 이미지 첨부 | 게시 완료 후 이동 |
| PANORAMA | 파노라마 촬영 | 파노라마 카메라 모드 | 촬영 완료 후 이동 |
| FACIAL | 얼굴 인식 | 전면 카메라 자동 실행 | 인식 성공 시 자동 이동 |

### 3.5 검증 여정

```
증거 제출 -> 검증 방식에 따라 분기
  [AUTO] -> 즉시 결과 표시 (성공/실패)
  [DELAYED] -> "검증 중" 상태 표시 -> 푸시 알림으로 결과 전달
  [MANUAL] -> "제작자 검토 중" 표시 -> 제작자 검토 -> 승인/반려 알림
```

| 검증 방식 | 사용자 대기 UX | 실패 시 처리 |
|-----------|---------------|-------------|
| AUTO | 1~3초 로딩 애니메이션 후 즉시 결과 | 재시도 버튼 노출, 남은 시도 횟수 표시 |
| DELAYED | 진행률 화면에 "검증 대기" 뱃지 표시, 예상 소요시간 안내 | 알림으로 사유 전달, 이의제기 버튼 |
| MANUAL | "제작자 검토 중" 상태 카드, 예상 검토 시간 | 반려 사유 상세 표시, 재제출 또는 이의제기 |

### 3.6 보상 여정

```
전체 Step 완료 -> 결과 화면 (점수, 순위, 소요시간)
-> 보상 수령 애니메이션 -> 보상 상세 확인
-> 지갑/뱃지 컬렉션 반영 -> 공유 (선택)
```

| 보상 유형 | 수령 UX | 사용 경로 |
|-----------|---------|-----------|
| 포인트 | 카운트업 애니메이션 | 내정보 > 포인트 지갑 |
| 뱃지 | 뱃지 획득 팝업 + 컬렉션 추가 효과 | 내정보 > 뱃지 컬렉션 |
| 쿠폰 | 쿠폰 카드 슬라이드 인 | 내정보 > 쿠폰 지갑 > 사용처 안내 |
| 경품 | 당첨 축하 화면 + 배송지 입력 요청 | 내정보 > 경품 수령 내역 |
| 추첨권 | 추첨권 적립 카운트, 추첨일 안내 | 이벤트 페이지 > 추첨 현황 |

### 3.7 제작 여정

```
[제작] 탭 -> "새 Clue 만들기" -> 템플릿 선택 또는 빈 Clue
-> 기본 정보 입력 (제목, 설명, 카테고리, 썸네일, 기간, 인원)
-> Step 추가 (유형 선택 -> 상세 설정)
-> 검증 방식 설정 (Step별)
-> 보상 설정 (유형, 수량, 조건)
-> 미리보기 -> 제출 (검수 요청)
```

| 단계 | 입력 항목 | UX 가이드 |
|------|-----------|-----------|
| 템플릿 선택 | 숨바꼭질/보물찾기/퀴즈대회/출석체크/스탬프투어 등 | 카드형 리스트, 미리보기 이미지, "빈 Clue로 시작" 옵션 |
| 기본 정보 | 제목(필수), 설명, 카테고리, 썸네일, 시작/종료일, 최대 인원 | 단계별 폼, 진행률 바, 임시저장 자동 |
| Step 추가 | Step 유형 선택, 제목, 설명, 증거 유형, 제한시간 | 드래그앤드롭 순서 변경, Step 복제/삭제, 최대 20개 |
| 검증 설정 | Step별 AUTO/DELAYED/MANUAL 선택 | 유형별 권장 검증 방식 자동 제안 |
| 보상 설정 | 보상 유형, 수량, 지급 조건(완주/순위/추첨) | 비용 시뮬레이션, 수수료 사전 고지 |
| 미리보기 | 참여자 시점으로 Clue 체험 | 실제 참여 화면과 동일한 UI |
| 제출 | 검수 요청, 예상 소요시간 안내 | 체크리스트(필수 항목 확인), 제출 확인 모달 |

### 3.8 승인 여정

```
Clue 제출 -> 검수 대기 -> 운영자 검토
-> 승인 -> 공개 설정 (즉시/예약)
   또는
-> 반려 -> 반려 사유 확인 -> 수정 -> 재제출
```

| 상태 | 제작자 화면 | 알림 |
|------|------------|------|
| PENDING_REVIEW | "검수 중" 뱃지, 예상 소요시간 | 제출 확인 푸시 |
| APPROVED | "승인 완료" 뱃지, "공개하기" CTA | 승인 완료 푸시 |
| REJECTED | "반려" 뱃지, 반려 사유 카드, "수정하기" CTA | 반려 알림 푸시, 사유 포함 |

### 3.9 커뮤니티 여정

```
[소통] 탭 -> 전체 게시판 / 클랜 탐색
-> 클랜 가입 또는 생성 -> 클랜 홈 (공지, 멤버, 클랜 Clue)
-> 클랜 채팅 -> 클랜 단위 Clue 참여
```

| 기능 | 설명 | 주요 UX |
|------|------|---------|
| 전체 게시판 | 자유/질문/후기/공략 게시판 | 카테고리 탭, 정렬(최신/인기), 검색 |

## 5. 권한 설계

### 5.1 권한 요청 정책

모든 권한은 **필요 시점 요청(Just-in-time)** 원칙을 따른다. 앱 최초 실행 시 일괄 요청하지 않는다.

| 권한 | 요청 시점 | 사전 설명 화면 | 거부 시 폴백 동작 | 재요청 전략 |
|------|-----------|---------------|-------------------|-------------|
| 위치 (ACCESS_FINE_LOCATION) | 지도 탐색 최초 진입 시, CHECKPOINT Step 수행 시 | "주변 Clue를 찾고 위치 미션을 수행하려면 위치 권한이 필요합니다" + 일러스트 | 지도: 기본 좌표(서울시청) 중심 표시, 수동 주소 검색 제공. CHECKPOINT: QR 스캔 대체 수단 안내 | 해당 기능 재진입 시 1회 재안내, 이후 설정 이동 링크만 표시 |
| 카메라 (CAMERA) | SNAPSHOT Step 수행 시, QR 스캔 시, 프로필 사진 변경 시 | "사진을 촬영하여 미션을 인증하려면 카메라 권한이 필요합니다" + 일러스트 | SNAPSHOT: "이 Step은 카메라가 필요합니다" 안내 + 설정 이동. QR: 수동 코드 입력 대체 | 기능 진입 시마다 안내 모달, 시스템 설정 딥링크 |
| 마이크 (RECORD_AUDIO) | 영상 촬영이 포함된 SNAPSHOT Step 시 | "영상 녹화에 마이크가 사용됩니다" | 마이크 없이 무음 영상 촬영 가능 (선택적 권한) | 영상 촬영 진입 시 안내 |
| 알림 (POST_NOTIFICATIONS) | 온보딩 완료 시 또는 첫 Clue 참여 시 | "Clue 진행 상황, 검증 결과, 보상 소식을 놓치지 않으려면 알림을 허용해주세요" + 일러스트 | 알림 미허용 시 앱 내 알림 센터(SCR-036)에서만 확인 가능. 주요 정보 미전달 위험 안내 | 중요 이벤트(첫 보상 수령 등) 시 1회 재안내 |

### 5.2 개인정보 보호 공지

| 항목 | 내용 |
|------|------|
| 위치 정보 | 위치 정보는 Clue 탐색 및 CHECKPOINT 검증에만 사용되며, 실시간 위치는 서버에 전송하지 않는다. CHECKPOINT 인증 시 인증 시점의 좌표만 전송한다. |
| 촬영 데이터 | 증거로 제출된 사진/영상은 검증 완료 후 제작자에게 공개되며, Clue 종료 후 90일 이내 자동 삭제된다. |
| 얼굴 데이터 | FACIAL Step의 얼굴 인식 데이터는 디바이스 내에서만 처리되며, 서버에 생체 정보를 전송하지 않는다. |
| 권한 철회 | 사용자는 언제든 시스템 설정에서 권한을 철회할 수 있으며, 앱 내 설정(SCR-041)에서 현재 권한 상태를 확인할 수 있다. |

| 정산 조건 | 최소 정산 금액 10,000원 이상 | 정산 상세 화면 |
| 환불 정책 | 참가비: Clue 시작 전 전액 환불, 시작 후 50% 환불 (진행률 10% 미만 시), 이후 환불 불가 | SCR-011 Clue 상세 (참가비 있는 경우), 이용약관 |
| 보상 예산 | 제작자가 사전 충전, 미사용 잔액 환불 가능 (수수료 공제 후) | SCR-027 보상 설정 화면 |

**정산 고지 표시 규칙:**
- 참가비 설정 시: "플랫폼 수수료 10%가 적용됩니다. 예상 수익: ₩{금액}"
- 정산 내역: 총 수익, 수수료, 세금, 실 정산액을 항목별로 분리 표시
- 정산 예정일과 입금 계좌를 정산 대시보드에 항상 노출

### 7.4 카드 컴포넌트

#### Clue 카드 (탐색 피드용)

```
+-----------------------------------------------+
| [썸네일 이미지]                    [찜 버튼]   |
|                                                |
| [카테고리 칩]  [난이도 칩]                     |
+-----------------------------------------------+
| Clue 제목 (최대 2줄)                           |
| 제작자 닉네임 · 예상 n분 · n명 참여 중         |
| [보상 아이콘] 포인트 100  [뱃지 아이콘] 뱃지 1 |
+-----------------------------------------------+
```

- 카드 크기: 가로 전체폭 - 32dp 마진, 세로 자동
- 썸네일: 16:9 비율, 라운드 코너 12dp (상단)
- 카드 배경: color-surface
- 그림자: elevation 2dp
- 터치 시: 약간의 스케일 다운(0.98) + Clue 상세(SCR-011)로 이동

#### Step 카드 (진행 화면용)

```
+-----------------------------------------------+
| [유형 아이콘]  Step 제목              [상태]   |
| Step 설명 (최대 1줄)                           |
| [제한시간 아이콘] 남은 시간: 05:00             |
+-----------------------------------------------+
```

- 현재 Step: 테두리 color-primary, 배경 강조
- 완료 Step: 체크 아이콘, 텍스트 취소선 없이 흐림 처리
- 잠긴 Step: 자물쇠 아이콘, 배경 color-disabled

### 7.6 안전 공지 디자인

오프라인 활동 Clue에 표시되는 안전 공지 컴포넌트:

```
+-----------------------------------------------+
| [경고 아이콘]  안전 안내                       |
|-----------------------------------------------|
| - 야외 활동 시 주변 교통 상황에 유의하세요.    |
| - 위험 지역(공사장, 절벽 등)에 접근하지 마세요.|
| - 야간 활동 시 밝은 옷을 착용하고 동행인과     |
|   함께하세요.                                  |
| - 긴급 상황 시 119에 신고해주세요.              |
|                                                |
| [v] 안전 안내를 확인했습니다.                   |
+-----------------------------------------------+
```

- 배경: color-warning (10% 투명도)
- 테두리: color-warning (왼쪽 4dp 굵은 선)
- 표시 시점: CHECKPOINT 또는 야외 활동 Clue 참여 시 최초 1회 필수 확인
- 체크박스 미선택 시: "참여하기" 버튼 비활성화
- Step 유형에 따른 추가 안전 공지:
  - CHECKPOINT (야간): "야간 이동 시 안전에 각별히 유의하세요."
  - FACIAL: "얼굴 인식은 디바이스에서만 처리되며, 서버에 저장되지 않습니다."
  - 수상 활동 관련: "수상 활동 시 반드시 구명조끼를 착용하세요."
