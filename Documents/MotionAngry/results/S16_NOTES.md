# S16: 사용자별 오프셋 베이스라인 — 누적 학습의 '전체 AUROC 상승'은 수준 보정인가 (2026-10-30, src/s16_offset_baseline.py → results/s16_offset_baseline.csv)

설정: K-EmoPhone 2Hz 블록 특징, 기본 모델(LOSO 50×3) 확률 p. 각 사용자의 처음 k개 응답으로 (평균 라벨 − 평균 확률)만 구해 p에 더하는 '오프셋' 보정(개인 모델 없음, 특징 학습 없음)을 S7의 blend(기본+개인 로지스틱 평균)와 비교. 평가는 k번째 이후 응답. 사용자 안 AUROC는 사용자별 단조 변환에 불변이므로 base = offset.

| 축 | k | 사용자 | 전체 AUROC base / blend / offset | 사용자별 평균 base / blend / offset |
|---|---|---|---|---|
| 각성 | 10 | 71 | 0.618 / 0.618 / 0.655 | 0.634 / 0.598 / 0.634 |
| 각성 | 20 | 71 | 0.628 / 0.637 / 0.672 | 0.653 / 0.617 / 0.654 |
| 각성 | 30 | 63 | 0.640 / 0.640 / 0.694 | 0.635 / 0.603 / 0.635 |
| 정서가 | 10 | 68 | 0.595 / 0.599 / 0.684 | 0.614 / 0.588 / 0.614 |
| 정서가 | 20 | 69 | 0.596 / 0.627 / 0.709 | 0.651 / 0.608 / 0.652 |
| 정서가 | 30 | 62 | 0.595 / 0.632 / 0.718 | 0.611 / 0.585 / 0.613 |

## 판단
- 특징을 전혀 다시 배우지 않고 그 사용자의 평균 수준만 맞추는 오프셋 보정이 전체 AUROC를 blend보다 훨씬 더 올린다(정서가 k=30: base 0.595 → blend 0.632 → offset 0.718). 즉 설문 응답 누적으로 얻는 '전체 AUROC 상승'은 사람 사이의 수준 차이 보정으로 설명되며, 개인 로지스틱이 배운 특징–정서 관계는 그보다도 못하다(사용자별 평균은 오히려 하락).
- 사용자 안 판별은 정의상 오프셋으로 바뀌지 않고, blend로도 오르지 않는다. 따라서 "그 사람 안의 변화"를 읽으려면 수준 보정이 아닌 다른 종류의 정보(촘촘한 피드백)가 필요하다는 S7 결론이 더 분명해진다.
- 논문 서술 예: "설문 응답으로 얻는 전체 AUROC의 상승은 그 사용자의 평균 수준을 맞추는 오프셋 보정 하나로 더 크게 재현되었고(정서가 0.595→0.718), 사용자 안의 판별은 두 방법 모두 올리지 못하였다. 설문 누적이 하는 일은 수준 보정이지 그 사람 안의 변화 학습이 아니다."
- 주의: 오프셋은 확률을 [0,1]로 잘라 더한 단순 보정이라 보정 뒤 확률은 교정(calibration)된 값이 아니다. 전체 AUROC 비교 목적에만 쓴다.
