# S1b 결과 메모 (WESAD 손목 가속도, 2026-10-05)

데이터: WESAD 15명, Empatica E4 손목 ACC 32Hz. 60초 창 / 15초 간격, LOSO, LightGBM.
코드: src/s1b_wesad.py → results/s1b_wesad.csv, s1b_wesad_tasks.csv, s1b_wesad_still.csv
특징 세트: coarse = 초 단위 3범주(정지/약/걷기) 비율·전이 (S1의 OS 활동추론 수준 흉내),
noori = 중력 방향 제외 원시 특징(고역 크기·스펙트럼·저크), raw = noori + 축별 통계·기울기, phys = EDA·BVP·TEMP

해석
- 강도를 맞추면(강도 단일 AUC ≈ 0.5) 거친 범주 특징은 우연 수준으로 무너지지만, 원시 미세 움직임 특징은 0.75~0.83 유지 → **S1과 일관: 정보는 해상도에 있다.**
- 거의 완전히 정지하면 모션도 무너짐(0.54), 생리 신호만 유지(0.80) → 모션 단독의 한계 경계를 정직하게 제시 가능.
- amusement vs baseline은 강도 교란이 남아(강도 단일 0.68~0.73) 정서가 주장 근거로 약함.

## 남은 위협 (논문 한계에 명시)
- 방향 정보를 뺐어도 서 있는 자세의 미세 동요(postural sway)가 원시 특징에 섞일 수 있음 — 자세와 스트레스가 WESAD 프로토콜에서 분리 불가.
- 실험실 유도 스트레스(TSST), 15명. 일상 환경 일반화는 K-EmoPhone 또는 N-of-1로 확인 필요.
