# S18: 개인화 베이스라인 공정 비교 (2026-10-30, src/s18_baselines.py → results/s18_baselines.csv) + S17b 0 제외 이진화 (src/s17b_zero_excluded.py)

리뷰어 지적(docs/reviewer_critique_2026-10-30.md M4·M6): 움직임 모델이 사소한 개인 베이스라인을 넘는지 보인 적이 없고, 응답 0(각성 16%, 정서가 22%)을 전부 음성으로 넣었다.

설정: K-EmoPhone 2Hz 블록 특징, 기본 모델(LOSO 50×3) OOF 확률. 각 사용자의 처음 k개 응답을 개인 자료로, k번째 이후에서 평가. 사용자별 AUROC는 평가 응답 20건 이상·두 부류. 차이(방법 − base)는 참가자 부트스트랩 500회 95% CI.

## 판단
1. 사용자 안 판별에서 움직임 기본 모델이 직전 응답(최근성)·시각 베이스라인보다 낫다. 각성 k=10에서 carry 대비 +0.059 [0.023, 0.098], hour 대비 +0.133 [0.081, 0.188]로 유의. 움직임 모델이 사람 사이 수준이 아니라 그 사람 안의 변화를 어느 정도 읽는다는 첫 직접 근거.
2. 전체 AUROC는 개인 사전확률·직전 라벨·오프셋 같은 '수준' 베이스라인이 움직임 모델을 크게 앞선다(정서가 k=30: prior 0.698, carry 0.726, offset 0.718 대 base 0.595). 전체 AUROC로 개인화를 평가하면 수준 보정이 전부를 설명한다는 S16 결론을 다른 베이스라인으로 재확인.
3. 32특징 개인 로지스틱(own32)은 1특징(feat1)과 사용자 안 판별이 같은 수준(0.555)이라, S7의 부정 결과가 32차원 과적합만의 문제는 아니다. 응답 10~30개로는 어떤 형태의 개인 모델도 기본 모델의 사용자 안 판별을 넘지 못했다.
4. 시각(hour)만으로는 사용자 안 판별이 우연 수준(0.51~0.55)이고, base에 시각을 더한 개인 로지스틱도 base보다 못하다. 일상 각성의 시간대 규칙성은 이 데이터에서 약하다.

## S17b: 응답 0 제외 이진화 (results/s17b_zero_excluded.csv)
| 축 | 0 비율 | 응답 수 | 양성 비율 | 전체 AUROC | 사용자별 평균 (사용자 수) |

0을 제외하면 각성은 0.623/0.623 → 0.634/0.632로 약간 오르고 정서가는 0.587/0.597 → 0.570/0.579로 약간 내린다(양성 비율 74%로 불균형 심화). 어느 쪽도 결론을 바꾸지 않는다. S17(중앙값 기준)과 함께 이진화 규칙 세 가지에서 사용자별 AUROC가 각성 0.62~0.64, 정서가 0.58~0.62로 유지된다.

## 논문 서술 예
"사용자 안 판별에서 움직임 기본 모델(각성 0.640)은 직전 응답을 그대로 쓰는 최근성 베이스라인(0.581)과 시각 베이스라인(0.507)보다 유의하게 높았다(차이 +0.059 [0.023, 0.098], +0.133 [0.081, 0.188]). 반면 전체 AUROC는 개인 평균 라벨이나 직전 라벨만으로도 0.65~0.73에 이르러 움직임 모델을 앞섰다. 전체 AUROC가 재는 것은 사람 사이의 수준이고, 그 사람 안의 변화를 읽는 것은 움직임 모델뿐이다."
