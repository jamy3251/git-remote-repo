# S15: 선택 편향 실증 — 모델이 고른 순간(급변 질문 A)으로만 평가하면 어떻게 되는가 (2026-10-30, src/s15_selection_bias.py)

결과 파일: results/s15_selection_bias_min20.csv(사용자별 지표는 응답 20건 이상), s15_selection_bias_min10.csv(10건 이상), 각 *_log.txt.

설정: K-EmoPhone 2Hz 블록 특징 3,771건·77명. 기본 모델(LOSO 50×3)의 out-of-fold 확률 p를 응답마다 두고, 사용자 안 시간순 연속 응답의 |Δp| ≥ δ인 응답을 "급변(A) 표본", 같은 사용자에서 같은 수를 무작위로 뽑은 응답을 "무작위(B) 표본"(200회 반복 평균)으로 삼아 비교. δ는 앱 규칙 0.25와 0.10·0.15·0.20. ESM 간격이 수 시간이라 |Δp| 분포(각성 중앙값 0.073, 90백분위 0.211)는 앱의 1분 단위와 다르다.

## 판단
1. 급변 순간의 응답은 무작위 응답과 다른 표본이다. 모델 확률이 더 극단적이고(δ=0.25에서 극단성 0.147 대 0.091, 약 1.6배), 양성 비율도 달라진다(각성 0.443 대 0.388).
2. 그 표본으로 잰 전체 AUROC는 무작위 표본과 다르며 방향이 일정하지 않다. δ=0.25에서는 부풀려지고(각성 0.672 대 0.624, 정서가 0.613 대 0.548), δ=0.15 정서가에서는 낮아진다(0.550 대 0.579). 즉 모델이 고른 순간으로 평가하면 점수가 표본 선택에 끌려 다닌다.
3. 사용자별 평가는 표본이 급격히 줄어 아예 불가능해진다. 앱 규칙(δ=0.25)과 같은 문턱에서는 응답 10건 이상인 사용자가 2명뿐이다. "그 사람 안의 판별"을 재려면 모델과 무관하게 꾸준히 들어오는 응답이 필요하다.
4. 개선폭 판단도 표본에 따라 두세 배 달라지므로, 학생 모델이 좋아졌는지는 무작위(B) 응답으로만 재야 한다는 설계 원칙의 근거가 된다.
5. 한계: ESM 간격(수 시간)에서 정의한 |Δp|는 앱의 1분 추정 급변과 같지 않다. 급변 표본이 작아 사용자별 차이의 신뢰구간은 넓다(δ=0.10에서만 +0.028 [−0.001, +0.054]). 이 분석은 "A로만 평가하면 안 된다"의 근거이지 "A 평가가 항상 과대평가"라는 주장은 아니다.

## 논문 서술 예
"모델이 고른 순간(급변 질문 A)의 응답만으로 평가하면 표본이 모델 확률이 극단적인 응답으로 치우쳐(|p−0.5| 평균 1.6배) 전체 AUROC가 무작위 응답 기준 0.62에서 0.67로 달라졌고, 사용자별 평가는 표본 부족으로 산출되지 않았다(응답 10건 이상 사용자 2명). 학생 모델의 개선폭도 평가 표본에 따라 두세 배 달라졌다. 모델이 좋아졌는지는 모델과 무관한 무작위 시각(B)의 응답으로만 재야 하는 이유이다."
