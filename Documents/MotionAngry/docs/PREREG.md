# PREREG — 사전 등록 (2026-10-30 17:15 고정, 이후 변경하지 않음)

데이터: K-EmoPhone 77명, 기본 모델과 같은 응답 집합(응답 직전 30분 손목 가속도 커버리지 ≥50%, 완전한 1분 창 ≥5개) 3,771건. 라벨 이진화: 각성·정서가 > 0 양성(기존 기준). 특징: 2Hz 블록 1분 특징 16개의 직전 30분 중앙값·IQR 32개(b2_*).

## RQ1 [필수] 기본 모델
- H1a: 32특징 LightGBM(50×3)의 LOSO AUROC가 활동 범주 모델보다 높고, 참가자 부트스트랩(1,000회) 95% CI가 겹치지 않는다. 1차 지표: 사용자별 AUROC 평균(평가 응답 ≥20·두 부류). 2차: 전체 AUROC.
- H1b: 15·30분 창의 사용자별 AUROC 평균이 1분·60분 창보다 높다(쌍대 차이의 참가자 부트스트랩 CI가 0을 제외).

## RQ2 [필수·핵심] 레이블 밀도 대 잡음
- 시뮬레이터(experiments/loop_sim): 각 사용자의 응답을 시간순으로 재생. 사용자 기간(첫 응답~마지막 응답)의 앞 60%를 학습 구간, 뒤 40%의 응답을 평가 응답(무작위 질문 B)으로 둔다.
- 교사 의사 라벨: 각 응답 직전 30분의 1분 구간마다(단말과 같은 '그 분까지의 직전 30분 요약' 32특징을 입력으로), 그 응답의 이진 라벨을 확률 1−p로 뒤집은 값. 밀도 d: 1분 구간 중 교사가 작동하는 비율(분마다 독립 베르누이). 편향 b: 뒤집을 확률을 음성에 (1−p)(1+b), 양성에 (1−p)(1−b)로 비대칭화(평균 뒤집기율은 유지, 교사가 양성으로 치우침).
- 학생: 단말 OnDeviceTrainer와 같은 식(표준화 상수 = 공개 데이터 전체 평균·표준편차, 로지스틱 33 파라미터, 전체 배치 경사하강 lr 0.05, 호출당 100스텝, 최근 2,000표본). 시작 가중치 = 다른 76명 데이터로 학습한 로지스틱(씨앗). 사용자 타임라인의 매 정시(1시간)마다 표본 ≥50이면 학습.
- 평가 응답 예측에는 그 응답 직전 30분의 교사 표본을 넣기 전의 가중치를 쓴다(진실 누출 방지).
- 비교 조건: (a) 기본 모델 고정 (b) 씨앗 + 선행 ESM 응답(30분 요약 1건=라벨 1건)으로 같은 학습식 파인튜닝 (c) 기본 모델 + 사용자별 Platt 보정(선행 ESM) (d) 씨앗 + 교사 의사 라벨 학생 (e) (d) + 성능 가드(14일·n≥15·−0.10/+0.05) 뒤 '학생 또는 기본' (f) 오라클 d=1·p=1·b=0.
- 격자: p ∈ {0.6, 0.7, 0.8, 0.9}, d ∈ {0.2, 0.5}, b ∈ {0, 0.2}, seed ∈ {0, 1, 2}. 1차 지표: 평가 응답에서 사용자별 AUROC(평가 응답 ≥10·두 부류)의 사용자 평균. 2차: 전체 AUROC, 일 단위 시간 경과.
- H2: 어떤 (p, d)에서 (d)의 사용자별 AUROC 평균이 (b)보다 높다(Wilcoxon 부호순위, 양측, α=0.05; 3 seed 평균). p*(d) = (d)가 (b)를 이기는 최소 p. 사전 예측: p* ≈ 0.8(d=0.5), p* ≈ 0.9(d=0.2). (d)가 (a)를 이기는지도 보고한다.
- 기각 시: 포지셔닝을 "어떤 교사 품질·밀도에서 자기 학습이 이기고 지는가"의 조건 분석으로 전환(지시서 7장).

## RQ3 [필수] 성능 가드
- 베르누이 시뮬레이션(experiments/guard_sim): 기본 정답률 q0 ∈ {0.55, 0.60, 0.65}, 학생 정답률 q1 = q0 + Δ, Δ ∈ {−0.20, …, +0.20} (0.05 간격), 하루 3회 프로브, 14일 창, 10,000회 반복. 가드: 고정 임계(10/5%p, n≥15), SPRT(α=β=0.05, 효과 크기 0.10), 베타-이항 사후확률(P(q1<q0−0.05) > 0.95), 부트스트랩 CI(차이 95% CI 상한 < 0).
- 지표: 검정력(Δ=−0.10에서 14일 안 복귀 확률), 오복귀율(Δ=0에서 복귀 확률), 복귀 지연(중앙값 일수), 재적용 진동 횟수.
- 사전 예측: 현행 고정 임계는 Δ=−0.10에서 검정력 <0.5, Δ=0에서 오복귀율 >0.2.

## RQ4 [필수] 선택 편향

- 사전 예측: A 표본 AUROC가 B보다 높게 치우친다(S15와 같은 방향).
