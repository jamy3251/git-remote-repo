# 자기 학습 루프 시뮬레이터 (experiments/loop_sim) — 설계·가정·한계

목적: PREREG RQ2(레이블 밀도 대 잡음), RQ4(선택 편향), 2.7(학생 개선)을 K-EmoPhone 77명 데이터 위에서 재생한다. 단말 코드와 같은 수식을 쓰고(테스트 tests/test_loop_sim.py), 모든 수치는 results/loop_sim/*.csv에서 나온다.

## 데이터 (build_minutes.py)
- 응답 집합: 기본 모델과 같은 3,771건(직전 30분 커버리지 ≥50%, 완전한 1분 창 ≥5). 응답 직전 60분의 1분 특징 16개(s6_build_2hz와 동일 계산) → `loop_minutes.parquet`(201,688분).
- 단말이 매 분 계산하는 '직전 30분 요약 32개'를 응답 전 1~30분째 각 분에 대해 만든다 → `loop_summaries.parquet`(110,634행). offset 1(응답 시각)의 요약은 기본 모델 입력(`kemophone_2hz_block.parquet`)과 **완전히 일치**(최대 차 0).

## 재생 (sim.py)
- 사용자별 시간순. 기간의 앞 60%는 학습 구간, 뒤 40%의 응답을 평가 응답(=무작위 질문 B)으로 둔다. 모든 예측은 그 응답의 라벨(과 그 응답에서 파생된 교사 라벨)을 쓰기 전에 만들어지므로 전 구간이 순차 예측이다.
- 교사: 응답 직전 30분의 분별 요약마다 응답 라벨을 확률 1−p로 뒤집은 의사 라벨. 밀도 d(분별 베르누이), 편향 b(음성 뒤집기 (1−p)(1+b), 양성 (1−p)(1−b)). 응답 사이의 잠재 정서는 만들지 않는다(가정 최소화).
- 학생: 표준화(공개 데이터 전체 mu/sd) → 로지스틱 33개. 단말 OnDeviceTrainer와 같은 전체 배치 GD(lr 0.05, 호출당 100스텝, 최근 2,000표본, ≥50표본), 사용자 기간의 매 정시마다 호출. 씨앗 = 다른 76명으로 학습한 L2 로지스틱(C=0.1, balanced; export_daily의 씨앗 식).
- 조건: base(LightGBM LOSO) · seed_model(씨앗, 갱신 없음) · esm_ft(씨앗 + 선행 ESM 응답으로 같은 학습식) · esm_sk(선행 ESM ≥10, sklearn L2 C=0.1) · platt(base + 사용자별 Platt) · student(교사) · guard(student + DriftGuard 규칙 → 학생 또는 base) · student_a{λ}/esm_a{λ}(씨앗으로 향하는 L2 앵커, λ∈{0.1,0.3,1}) · oracle(p=1,d=1).
- 격자: p∈{0.6,0.7,0.8,0.9} × d∈{0.2,0.5} × b∈{0,0.2} × seed∈{0,1,2} + oracle×3. 셀당 약 20~50초(22 프로세스).
- 지표(experiments/common/eval.py): 사용자별 AUROC(평가 응답 ≥10·두 부류) 평균, 전체 AUROC, base·esm_ft 대비 차이의 참가자 부트스트랩 95% CI, Wilcoxon 부호순위.

## 한계(논문 Discussion에 쓸 것)
1. 교사 라벨은 응답 라벨의 복사본이므로 **새 정보가 없다**: 고밀도 라벨의 이점 중 '응답 사이의 상태를 본다'는 부분은 이 시뮬레이터가 재현하지 못한다. 재현하는 것은 (i) 잡음·편향이 학생에 미치는 영향, (ii) 같은 정보량에서 단말 학습식의 거동, (iii) 가드의 작동.
2. 손목 가속도. 3. 사용자당 약 6일·49응답.
