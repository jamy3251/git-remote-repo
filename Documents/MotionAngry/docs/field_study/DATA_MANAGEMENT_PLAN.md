적용 범위: `PROTOCOL.md`의 4주 현장 연구에서 참가자 폰에 생기는 자료와 연구자가 회수한 복사본. 공개 데이터(K-EmoPhone)는 각 데이터셋의 이용 약관을 따르며 여기서 다루지 않는다.

## 2. 식별자와 가명화

- 참가자 코드: `F01`, `F02`, … (`F` = field). K-EmoPhone의 `P01…P77`과 겹치지 않게 접두를 다르게 둔다. 코드는 앱 설치 시 입력되어 `events.csv` `consent` 값과 회수 폴더 이름에만 쓰인다 `[앱 변경 필요: 참가자 코드 입력, APP_READINESS_CHECKLIST 2절]`.
- 연결표(코드 ↔ 이름·연락처·서명 동의서 번호·보상 지급 여부): 단일 파일 `field_keymap.xlsx`를 **연구 자료 폴더와 다른 위치**에 암호화(7-Zip AES-256 또는 VeraCrypt 볼륨) 보관. 접근자는 PI 1인. 보상 지급과 IRB 종료 보고가 끝나면 삭제하고 삭제일을 `field_log.md`에 적는다.
- 서명 동의서(종이): 지도교수 연구실 잠금 서류함. 전자 서명이면 PDF를 연결표와 같은 암호화 볼륨에.
- 로그 안의 간접 식별자: `events.csv`의 `app`·`media` 열(앱 이름·곡 제목)은 참가자가 동의서 선택 5번에 "아니오"면 단말에서부터 해시로 기록된다. "예"인 참가자의 원문도 분석 후 공개 자료에서는 제거한다. `wall_ms`(벽시계)는 생활 리듬을 드러내므로 공개 시 일 단위 오프셋을 더해 상대 시각으로 바꾼다.

## 3. 단말 → 연구자 전달

전송 경로는 **USB 유선 복사 1가지**만 쓴다. 메신저·이메일·클라우드 업로드는 참가자에게도 요청하지 않는다.

절차(종료 방문, 연구자 노트북):
1. 참가자 입회 아래 USB 연결. `adb pull /sdcard/Android/data/kr.ac.seoil.motionaffect/files/ <회수루트>/F01/` (Git Bash에서는 `MSYS_NO_PATHCONV=1` 접두, `adb -s <serial>` 지정). adb 사용이 어려운 기기는 MTP로 같은 폴더 복사.
2. 체크섬: `find F01 -type f -exec sha256sum {} \; > F01.sha256` 을 단말 쪽(adb shell `sha256sum`)과 PC 쪽에서 각각 만들어 비교. 불일치 파일은 다시 복사.
3. 파일 수·총 크기·`events.csv` 첫/마지막 `wall_ms`·`affect.csv` 행 수를 `field_log.md`에 기록(회수 완료 증빙).
4. 참가자에게 단말 삭제 여부를 묻고, 삭제를 원하면 앱 '기록 삭제' 버튼(`[앱 변경 필요: T12]`) 또는 앱 삭제를 입회 확인. 삭제를 원하지 않으면 그대로 두되 연구자는 이후 접근하지 않는다.
5. 회수 즉시 노트북의 평문 복사본을 암호화 볼륨으로 옮기고 평문을 삭제한다(노트북에 평문을 남기지 않음).

## 6. 공개 계획

- **기본 방침**: 원시 IMU·표정 계수·`events.csv`는 공개하지 않는다. 논문·저장소에는 집계 결과(사용자별 AUROC 표, 부트스트랩 CI, 가드 전환 횟수, 응답률)와 분석 코드만 공개한다.
- **조건부 공개 후보**: 동의서 선택 6번에 동의한 참가자의 "응답 시점 30분 요약 특징 32개 + 이진 라벨 + 출하/학생 확률"(응답당 1행). 공개 전에 아래를 확인한다.
  - 재식별 위험 근거: 같은 32특징 1창으로 K-EmoPhone 77명 중 누구인지 맞히는 top-1 정확도 **7.0%**(Wilson 95% CI 5.8~8.4%, n=1,479; 우연 1.3%, 라벨 섞은 대조군 2.2%) — `results/S14_NOTES.md`. 식별 정보는 우연의 약 5배로 "있지만 인증 수준은 아니다".
  - 현장 참가자는 수가 적어(`[PENDING]`명) 후보 집합이 작고, 공개 자료 안에서 참가자끼리 구별되는 것 자체는 코드로 이미 드러나므로, 실제 위험은 **외부 자료와의 연결**(같은 사람의 다른 가속도 기록)이다. PREREG RQ6의 후보 수 77/20/10 결과를 보고, 후보 10명에서 식별률이 우연의 5배를 넘으면 특징 공개를 하지 않고 집계만 공개한다.
  - 공개 시 처리: 코드 재부여(`F01`→무작위), `wall_ms` → 참가자별 무작위 오프셋 상대 시각, `app`·`media` 제거, 요약 특징 소수 3자리 반올림.
- 공개 저장소: 논문 게재 후 Zenodo(DOI) 또는 GitHub Releases. 라이선스 CC BY-NC 4.0 `[PENDING: 지도교수 확인]`.
- 분석 코드(`docs/field_study/analysis_skeleton.py` 완성판, `experiments/common/eval.py`)는 자료와 무관하게 공개한다.
