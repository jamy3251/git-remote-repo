## 요 약
본 논문에서는 스마트폰이 움직이는 양상(가속도 센서 데이터)으로부터 사용자의 현재 기분, 즉 정서 상태를 추정하는 온디바이스(on-device) 시스템을 다룬다. 기분이 움직임에 드러나는 방식은 사람마다 다르므로, 사용자가 스마트폰을 쓰는 동안 얻는 정서 피드백을 서버로 보내지 않고 단말 안에서 바로 모아 학습함으로써 추정 모델을 그 사용자에게 맞게 개인화하는 자기 학습 구조를 설계·구현하였다. 구체적으로, 화면을 보는 동안 전면 카메라에 MediaPipe 표정 분석을 적용하여 얻은 표정 정보를 교사 데이터로 삼고, 32개의 움직임 특징으로부터 정서를 추정하는 경량 학생 모델(student model)을 1시간마다 단말 내에서 갱신하였다. 또한 1일 3회 무작위 시각에 사용자에게 직접 기분을 묻는 기분 지도(Affect Grid) 응답으로 학습된 모델과 기본 모델의 정확도를 비교하고, 학습 후 오히려 성능이 떨어지면 기본 모델로 자동 복귀시키는 성능 가드를 두어 수집·학습·평가가 단말 내에서 완결되는 순환 학습 구조를 구성하였다. 공개 일상 데이터셋(77명, 응답 3,771건)을 이용한 분석 결과, 응답 직전 15~30분의 움직임 특징이 해당 시점의 정서와 가장 높은 대응을 보였으며, 1일 수회의 설문 응답 누적만으로는 개인 내 정서 변화를 학습하기에 불충분하여 사용 중 즉시 수집되는 피드백이 필요함을 확인하였다. 실제 단말에서 학생 모델의 100스텝 학습은 23~44ms, 메모리 약 1MB가 소요되어 백그라운드 실행에 부담이 없었으며, 모델 입력인 32차원 움직임 특징만으로는 사용자 식별이 불가능하여 특징값이 단말 외부로 유출되더라도 신원이 보호됨을 확인하였다.

## I. 서 론

스마트폰은 내장 가속도 센서(accelerometer)를 통해 사용자의 움직임을 상시 기록할 수 있다. 이러한 움직임 데이터로부터 사용자의 각성(arousal, 흥분·활성화 수준)과 정서가(valence, 유쾌·불쾌 정도)를 추정할 수 있다면, 정신 건강 관리, 집중 관리, 콘텐츠 추천과 같이 사용자 상태에 적응적으로 반응하는 서비스의 구현이 가능하다. 그러나 정서 정보는 그 자체로 민감한 개인정보이므로, 본 연구는 추정과 학습을 모두 단말 외부로 내보내지 않는 온디바이스(on-device) AI를 구현 환경으로 설정하였다[1]. 그리고 공개 일상 데이터셋 K-EmoPhone(77명의 일상 움직임과 정서 응답 기록)으로 만든 기본 모델에 저자 개인의 기록을 더해 학습시킨 개인용 온디바이스 모델이 개인의 각성과 정서를 추정할 수 있는지를 가설로 세워 검증하였다. 어느 정도의 움직임을 각성 상태로 판단할지에 대한 기준은 개인마다 상이하다. 이 기준을 사용자의 단말이 해당 사용자의 정서 피드백으로 학습한다면, 모든 사용자에게 공통인 모델이 해당 개인에게 적합한 모델로 전환될 수 있다. 본 논문에서 정서 피드백이란 사용자가 단말을 사용하는 중에 자신의 정서에 관해 제공하는 모든 응답을 의미하며, 기분 지도 화면에 직접 입력한 응답과 전면 카메라 표정으로부터 자동 생성되는 임시 정답(pseudo-label)을 포함한다. 본 논문은 이러한 피드백을 사용 중 즉시 수집하여 단말 내에서 학습하는 구조를 제안한다. 화면 사용 중의 표정을 교사 데이터로 활용하여 1분 단위로 임시 정답을 생성함으로써 피드백의 연속성을 확보하고, 학습된 모델의 개선 여부는 모델의 추정과 무관한 무작위 시각의 응답만으로 평가하여 평가 데이터가 모델의 추정에 의해 편향되는 것을 방지하며, 성능이 저하된 모델은 자동으로 복귀시킨다. 공개 데이터셋 분석 결과, 각성이 높을수록 신체 움직임이 빈번하고 급격해져 직전 30분의 저크(가속도 변화율)가 클수록 각성이 높게 나타났으며, 이러한 경향은 전체 사용자의 87.5%에서 동일하게 관찰되었다. 이 관계에 기반한 경량 모델은 인터넷 권한이 없는 애플리케이션 내에서 학습에 포함되지 않은 사용자의 각성을 AUROC(Area Under the ROC Curve) 0.62로 추정하였다.

## II. 관련 연구

온디바이스 AI는 모델 추론을 서버가 아닌 스마트폰·웨어러블·IoT 기기 내부에서 수행하는 기술로, 데이터가 기기 외부로 전송되지 않아 개인정보 유출을 방지하고 네트워크 지연과 서버 비용이 발생하지 않는 장점으로 인해 최근 빠르게 확산되고 있다[1]. 초경량 모델에서 출발하여 칩셋의 신경망 처리 장치(NPU)와 함께 대형 언어 모델까지 단말에서 실행하는 단계로 확장되었으며, 가속도와 같은 1차원 센서 시계열 모델은 영상·언어 모델 대비 크기가 매우 작아 단말 탑재에 가장 유리한 영역으로 평가된다[1]. 단말 내 학습 또한 LiteRT가 학습 함수를 모델 파일에 포함하는 기능을 지원하면서 가능해졌으며, 공식 예제는 수만 개 파라미터의 이미지 분류기를 기기에서 추가 학습하는 것이다[4]. 본 논문은 동일한 방식을 33개 파라미터의 센서 시계열 정서 모델에 적용한다. 정서 추정의 정답(label)으로는 설문, 콘텐츠 시청 중 직접 입력한 감정[5], 표정 계수[2] 등이 활용되어 왔으며, 같은 사람의 데이터를 학습과 평가에 함께 쓰지 않으면 성능이 크게 낮아진다는 보고[5]는 개인화의 필요성을 보여 준다. 표정을 직접 정서 추정에 사용하거나[2] 손목형 기기의 생체 신호로 스트레스를 탐지한[3] 기존 연구와 달리, 본 연구는 표정을 학습의 교사 데이터로만 사용하고 최종 추정은 카메라가 비활성화된 시간에도 획득 가능한 움직임 데이터만으로 수행한다. 이를 위해 공개 일상 데이터셋으로 기본 모델을 구성하고 개인화에 필요한 피드백의 조건을 확인하며, 자기 학습 순환 구조를 안드로이드 애플리케이션으로 구현하여 실사용 환경에서 동작을 검증하고, 단말 내 학습 비용을 측정하며, 모델 입력인 32차원 특징이 신원 정보를 포함하지 않아 특징값 유출 시에도 개인정보가 보호됨을 확인한다.

## III. 시스템 설계

### 3.1 전체 구조

제안하는 자기 학습 순환 구조는 그림 1과 같이 정서 추정, 피드백 수집, 학생 모델 갱신, 성능 가드의 네 단계가 단말 내에서 하나의 순환 고리를 이루어 반복된다. 추정 경로에서는 가속도 센서 데이터로부터 움직임 특징을 산출하고 기본 모델과 학생 모델이 각각 정서 확률을 출력한다. 피드백 경로에서는 전면 카메라 표정 분석과 기분 지도 응답을 통해 정답을 수집한다. 학습 경로에서는 표정 기반 임시 정답으로 학생 모델을 주기적으로 갱신하고, 성능 저하 방지를 위하여 무작위 시각의 응답을 기준으로 두 모델을 비교하여 적용 모델을 결정한다. 모든 데이터와 모델은 단말 내 파일로만 관리된다.

### 3.2 핵심 구성요소 및 동작

정서 추정 모듈은 가속도 센서 값을 초당 약 50회 수신하여 1분 단위로 초당 2회로 다운샘플링한 뒤, 움직임의 크기·급격함·정지 시간 등 16개의 특징값을 산출한다. 이 특징값의 직전 30분 구간 중앙값과 사분위 범위를 계산하여 32차원 특징 벡터를 구성하고, 이를 결정 트리 50개로 구성된 기본 모델에 입력하여 각성 및 정서가 확률을 출력한다. 기본 모델은 타 사용자 데이터로 학습한 공통 기준이므로, 해당 사용자 개인의 기준을 학습할 학생 모델을 동일한 32차원 특징 위에 병렬로 배치한다. 학생 모델은 가중치 32개와 편향 1개로 구성된 로지스틱 회귀(logistic regression) 모델이다. 충전 중이거나 화면이 꺼진 상태에서 1분간 움직임이 없는 경우에는 단말이 거치된 상태로 판단하여 추정을 보류하고 기록만 수행하며, 이를 비접촉 보류라 정의한다.

피드백 수집 모듈은 화면이 켜진 동안 전면 카메라 영상을 초당 2프레임으로 MediaPipe 프레임워크[6]의 얼굴 분석 모델에 입력하여 웃음·입 벌림 등 52개 표정 계수만을 추출하며, 영상은 저장하지 않는다. 기분 지도는 Affect Grid[7]의 두 축인 불쾌~유쾌(가로)와 차분~흥분(세로)을 따르되, 9×9 격자 대신 연속 좌표와 색상으로 표현한 입력 화면이다. 사용자가 화면을 1회 터치하면 정서가·각성 값과 강도, 가장 가까운 감정 명칭이 기록되며, 단말의 현재 추정에 대한 정오(맞음/틀림) 응답도 함께 수집한다. 기분 지도는 두 가지 조건에서 제시된다. 급변 질문(A)은 각성 추정값이 직전 질문 시점 대비 0.25 이상 변화한 경우 30분당 1회를 상한으로 제시하고, 무작위 질문(B)은 추정과 무관하게 1일 3회 난수 시각에 제시한다. 모델 개선 여부의 평가에는 B의 응답만을 사용하는데, A는 모델이 선택한 시점이므로 평가에 포함할 경우 모델의 추정 결과가 평가 데이터를 편향시키기 때문이다.

학생 모델 갱신 모듈은 표정 분석 결과를 교사 데이터로 사용한다. 1분간의 웃음 계수 평균이 기준값을 초과하면 "기분 좋음", 입 벌림 계수 평균이 기준값을 초과하면 "들뜸"으로 임시 정답을 부여하고, 얼굴이 충분히 검출되지 않은 구간은 제외한다. 기준값은 초기 수일간의 기록으로 결정하여 파일로 저장한다. 임시 정답이 부여된 1분 구간의 32차원 특징을 누적하고, 1시간마다 50건 이상 누적된 경우 100스텝의 경사하강법(gradient descent)으로 학생 모델의 가중치를 갱신하여 저장한다.

성능 가드는 학생 모델이 반복 갱신 과정에서 오히려 성능이 저하되는 것을 방지하는 안전장치이다. 무작위 질문 B의 응답이 수집될 때마다 기본 모델과 학생 모델의 추정을 동일 응답에 대해 채점하고, 최근 14일간의 응답이 15건 이상 누적되면 두 모델의 정답률을 비교한다. 학생 모델의 정답률이 10%포인트를 초과하여 낮으면 기본 모델로 복귀하고, 5%포인트를 초과하여 높으면 학생 모델을 재적용한다. 복귀와 재적용의 임계값을 서로 다르게 설정한 것은 히스테리시스(hysteresis) 방식으로 경계 부근에서 모델이 반복적으로 전환되는 현상을 억제하기 위함이다. 현재 적용 중인 모델의 확률이 알림 표시와 급변 질문 A의 기준이 되며, 1분마다 두 모델의 확률, 특징값, 표정 평균, 자세, 비접촉 여부를 1행으로 기록한다.

### 3.3 구현

제안 구조는 인터넷 권한이 없는 안드로이드 애플리케이션으로 구현하였다. 단일 백그라운드 서비스가 센서 수집, 1분 특징 및 30분 요약 특징 산출, 두 모델의 추정, 알림 표시를 담당하며, 화면이 켜지면 전면 카메라 영상에서 표정 계수를 추출하여 1분 단위로 평균한다. 기본 모델은 트리 구조를 텍스트 파일로 변환하여 Java로 실행하고, 학생 모델은 LiteRT 인터프리터가 학습·추론·가중치 입출력을 담당한다. 모델 파일과 교사 기준값은 애플리케이션 내부 폴더의 파일을 우선 로드하도록 구성하여 재설치 없이 교체가 가능하며, 무작위 질문 시각은 운영체제 알람에 등록하여 애플리케이션 재시작 및 재부팅 이후에도 유지된다. 애플리케이션 종료 중의 기분 지도 입력은 별도 보관 후 다음 실행 시 병합한다. 모든 기록은 단말 내 파일로만 저장된다. 화면은 두 개로 구성하였다. 메인 화면은 기록 상태, 최근 30분의 추정 결과, 표정 교사와 학생 모델의 상태, 권한 허용 여부를 표시하고, 기분 지도 화면은 단말의 추정과 정오 응답, 색상 지도, 자동 선택된 감정 명칭을 한 화면에 배치하였다(그림 2).

## IV. 실험 및 평가

### 4.1 실험 환경 및 데이터셋

공개 데이터셋으로는 K-EmoPhone[8]을 사용하였다. 대학생 77명이 7일간 1일 수회의 무작위 알림에 응답하여 해당 시점의 정서가·각성·스트레스를 −3~+3 척도로 기록하고, 손목 밴드의 가속도가 초당 약 8회로 함께 수집된 데이터셋이다. 해당 데이터셋에는 스마트폰 가속도 센서의 원시 신호가 포함되어 있지 않고 정지·도보·차량 등의 활동 분류 결과만 제공되므로, 신체에 접촉한 기기의 움직임이라는 점에서 동일한 손목 밴드 가속도를 스마트폰 가속도의 대용으로 사용하였다. 각 응답을 해당 시점 정서의 정답으로, 응답 직전 30분의 가속도를 입력으로 하여 총 3,771건을 사용하였으며, 이는 단말이 최근 30분을 요약하여 추정하는 조건과 동일하다. 단말과 동일한 연산이 되도록 4개 샘플씩 평균하여 초당 2회로 변환하였다.

성능 지표로는 AUROC를 사용하였다. AUROC는 모델이 두 상태(예: 들뜸/차분)를 구분하는 능력을 나타내는 지표로, 0.5는 무작위 수준, 1은 완전한 구분을 의미한다. 전체 응답을 통합하여 산출한 전체 AUROC는 사용자 간 평균 수준의 차이만 구분하여도 상승하므로, 개인 내 변화의 추적 여부는 사용자별 AUROC의 평균으로 별도 평가하였다. 응답 누적 실험은 각 사용자의 응답을 시간순으로 정렬하여 선행 k건으로 해당 사용자의 모델을 학습한 뒤 후속 응답으로 평가하는 방식으로 수행하였다. 개발 환경은 표 1과 같으며, 단말 실험은 표 1의 스마트폰 1대에서 수행하였다. 정답 이진화, 학습·평가 데이터 분리, 질문 예약, 성능 가드, 교사 규칙의 동작은 단위 테스트 44개로 검증하였다.

### 4.2 실험 결과

움직임 특징만으로 구성한 기본 모델은 학습에 포함되지 않은 사용자의 각성을 AUROC 0.623, 정서가를 0.587로 추정하였다. 운영체제가 제공하는 활동 분류(정지·도보·차량)만으로 구성한 모델의 각성이 0.546에 그친 것과 비교하면, 활동 범주로는 담기지 않는 정서 정보가 움직임 특징에 포함되어 있음을 알 수 있다. 특징을 산출하는 구간의 길이에 따라서도 성능이 달라졌는데, 응답 직전 1분만 사용하면 각성 0.594, 정서가 0.558로 낮아지고 15~30분에서 각각 0.62~0.63, 0.58~0.59로 가장 높았으며 60분으로 늘리면 다시 낮아졌다. 참가자 단위 부트스트랩(1,000회)으로 짝지어 비교하면 30분과 1분의 차이는 각성 +0.027 [95% CI 0.008, 0.047], 정서가 +0.026 [0.001, 0.049]로 유의하였고, 10~30분 사이의 차이는 신뢰구간이 0을 포함하였다. 이는 그 순간의 정서가 순간의 움직임보다 직전 수십 분 동안의 움직임 양상에 반영된다는 점을 보여 준다.

개인화에 어떤 피드백이 필요한지는 응답 누적 실험에서 드러났다. 기본 모델에 사용자 본인의 설문 응답을 30건까지 누적하여 함께 학습하자 전체 AUROC는 정서가에서 0.595에서 0.632로 올랐지만, 사용자별 평균 AUROC는 0.611에서 0.585로 오히려 내려갔다(두 차이 모두 신뢰구간이 0을 포함). 개인 모델을 쓰지 않고 그 사용자의 평균 수준만 맞추는 오프셋 보정만으로도 전체 AUROC는 0.718까지 올랐고 사용자별 평균은 정의상 변하지 않았으므로, 설문 누적으로 얻는 전체 AUROC의 상승은 사용자 사이의 수준 차이 보정으로 설명된다. 하루 몇 차례의 설문 응답은 사용자 사이의 평균적인 정서 수준 차이를 구분하는 데에는 도움이 되지만, 한 사용자 안에서 시간에 따라 변하는 정서를 학습하기에는 너무 드물기 때문으로 해석된다. 즉 개인화에는 간헐적인 설문이 아니라 사용 중에 즉시 들어오는 피드백이 필요하며, 표정을 교사 데이터로 삼아 1분 단위로 정답을 만들고 단말 안에서 바로 학습하도록 한 본 연구의 설계는 이 결과에 근거한다.

이렇게 설계한 순환 구조가 실제 단말에서 부담 없이 동작하는지도 확인하였다. 학습 함수를 포함한 LiteRT 모델을 단말에 탑재하고 64건의 데이터로 100스텝을 학습한 결과, 학습 시간은 22.7~44.4ms, 메모리는 0.9~1.3MB였으며 출력 확률은 PC 학습 환경과 10⁻⁸ 이내로 일치하였다. 1시간에 한 번 수행하는 학습이 0.05초 안에 끝나므로 사용자가 인지하지 못하는 비용으로 백그라운드에서 동작할 수 있다. 실사용 환경에서도 기분 지도 입력, 무작위 질문의 예약과 중복 방지, 종료 중 입력의 보존, 교사 기준값의 설정까지 모든 기능이 설계대로 동작하여, 수집·학습·평가가 단말 안에서 하나의 고리로 닫힘을 확인하였다.

설계의 전제가 된 가정들도 공개 데이터셋으로 검증하였다. 무작위 질문으로만 평가하는 설계의 근거로, 모델의 추정이 크게 변한 순간의 응답만 골라 평가하면 그 표본은 모델 확률이 극단적인 응답으로 치우쳐(|p−0.5| 평균 1.6배) 전체 AUROC가 무작위 표본 기준 0.62에서 0.67로 달라졌고, 앱 규칙과 같은 문턱에서는 사용자별 평가가 가능한 사용자가 2명뿐이었다. 비접촉 보류 규칙은 전체 구간의 18.3%를 보류하였는데, 보류된 구간의 각성 AUROC가 0.595로 나머지 구간의 0.623보다 낮아 방향은 설계와 맞았으나 차이의 신뢰구간은 0을 포함하였다(+0.028 [−0.021, 0.080]). 라벨을 0 기준 대신 사용자별 중앙값 기준으로 바꿔도 사용자별 평균 AUROC는 각성 0.63, 정서가 0.62로 유지되어 결과가 이진화 기준에 좌우되지 않았다. 또한 동일한 32차원 특징으로 사용자를 식별해 보았을 때 창 1개로는 7.0% [5.8, 8.4], 창 10개를 모아도 18.6%만 맞혀 대부분의 사용자를 가려내지 못하였다. 이 특징값이 정서를 읽는 데에는 쓰이지만 사람을 알아보는 데에는 쓰이지 않는다는 뜻이며, 특징값이 단말 밖으로 나가더라도 신원이 보호된다는 본 연구의 주장이 이로써 뒷받침된다. 종합하면, 제안 구조는 서론의 가설과 설계 전제를 실험으로 확인하면서 단말 내에서 개인화 학습을 완결하였다.

## V. 결론

본 논문에서는 스마트폰 가속도 센서 데이터로 각성·정서가를 추정하는 온디바이스 시스템에서, 사용 중 수집되는 정서 피드백을 단말 내에서 즉시 학습하는 자기 학습 순환 구조를 제안·구현하였다. 공개 일상 데이터셋 분석 결과, 직전 15~30분의 움직임 특징이 해당 시점의 정서와 가장 잘 대응하였으며, 1일 수회의 설문 응답 누적만으로는 개인 내 정서 변화를 학습할 수 없어 즉시 수집되는 피드백이 필요함을 확인하였다. 이에 표정 교사 데이터, 두 경로의 기분 지도 질문, 성능 가드, 단말 내 학습을 하나의 순환 구조로 통합하여 인터넷 권한이 없는 애플리케이션으로 구현하고, 질문 예약·입력 보존·모델 전환·교사 활성화까지 실사용 환경에서 동작을 검증하였다. 1시간 주기의 학습은 0.05초와 메모리 약 1MB의 비용으로 수행되어 사용자가 인지하지 못하는 수준이었으며, 모델 입력인 32차원 특징만으로는 사용자 식별이 불가능하여 특징값 유출 시에도 신원이 보호됨을 확인하였다.

제안 구조가 의도대로 동작하면 단말은 사용자에게 질문하지 않고도 현재의 정서를 추정하고, 그 추정은 사용자 자신의 반응으로 지속적으로 보정된다. 영상·음악 애플리케이션은 어떤 콘텐츠에서 사용자의 각성이 상승·하강하는지를 단말 내에서만 학습하여 추천과 재생 순서에 반영할 수 있으며, 정신 건강 및 집중 관리 애플리케이션은 평소와 다른 하루를 감지하여 선제적으로 개입하거나 각성이 저하되는 시간대를 안내할 수 있다. 이 모든 동작은 표정과 원시 센서 신호를 단말 외부로 전송하지 않은 상태에서 이루어진다.

본 연구는 저자 1인의 실사용 기록을 중심으로 공개 일상 데이터셋 77명을 보조 근거로 활용하여, 제한된 자료 내에서도 즉각적인 피드백 수집과 학습을 단말 내에서 완결하는 구조의 구현과 설계 전제의 검증에 성공하였다. 교사 기준값과 성능 가드의 임계값은 2일간의 기록으로 설정한 초기값이며, 학생 모델이 실제로 해당 사용자에게 더 적합해지는지는 무작위 질문 응답이 수 주 누적된 이후 평가하는 것을 향후 연구로 남긴다.
