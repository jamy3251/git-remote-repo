# MotionAngry 연구 계획 (IAAI 2026, 4쪽, 1인)

작성: 2026-10-04

## 가제

모션 센싱 기반 정서 추정과 소비 맥락 해석을 위한 온디바이스 에이전트: 실현 가능성 연구

## 핵심 주장 (3개, 이 이상 늘리지 않음)

1. 폰·손목 모션 신호만으로 각성/정서가/스트레스를 우연보다 높게 추정할 수 있으나, 성능 상한은 낮다 (정직한 수치).
2. 정서 상태와 쇼핑 앱 사용 사이에 시간적 연관이 있다 → 소비 맥락 해석의 근거.
3. 추정·해석·개입 문구 생성 파이프라인이 외부 전송 없이 폰 안에서 실시간 동작한다.

주장하지 않음: 에이전트 개입이 충동구매를 줄인다 (향후 연구로 실험 설계만 제시).

## 차별점 (선행연구 대비)

| 선행 | 한 것 | 우리가 다른 점 |
|---|---|---|
| Wampfler et al. 2022 (ETH, 82명 10주) | 터치+관성센서 CNN, 관성만으로 AUC 0.83 | 정확도 경쟁 X. 소비 맥락 연결 + 온디바이스 에이전트 |
| K-EmoPhone (Kang et al., Sci Data 2023) | 77명 7일, 베이스라인 macro F1 0.52~0.54 (LOSO) | 모션 단일 모달리티 분석 + 앱 카테고리 기반 소비 해석 |
| StudentLife (Wang et al., UbiComp 2014) | 48명 10주 폰 센싱 + PAM/스트레스 EMA | 소비 맥락·에이전트로 확장 |
| 모바일 쇼핑 충동구매 연구 (PAD 모델) | 설문 기반 쾌·각성 → 구매충동 | 설문이 아닌 수동 센싱으로 정서 추정 |
| 모바일 에이전트 (AutoDroid 등) | 앱 조작 자동화 | 사용자 정서 상태를 맥락으로 사용 |

인용은 원문 확인 후 확정. Wampfler 2022가 가장 강한 선행이라 반드시 언급.

## 실험 (4쪽에 맞춤)

- S1 정서 추정: 모션 특징만 (활동 비율, 전이 빈도, 손목 가속도 통계·주파수) → LightGBM, LOSO, 이진(High/Low). 비교: 다수클래스 / 전체 모달리티 / 모션만. 지표 macro F1, AUROC.
- S2 소비 맥락: 쇼핑 앱 사용 세션 전 30/60분의 정서 라벨 및 S1 추정값 비교. 혼합효과 로지스틱 회귀 (참가자 랜덤효과).
- S3 온디바이스: 본인 Android 폰. TFLite 분류기 + 소형 LLM(Gemma 계열)로 해석·개입 문구 생성. 지연시간, 배터리 %/h, 메모리, 네트워크 전송 0 확인.
- (지면 남으면) N-of-1 사례 1문단.

## 4쪽 구성

1. 서론 (0.5p): 문제, 윤리 프레이밍(사용자 편 에이전트), 기여 3개
2. 관련 연구 (0.5p): 모바일 정서 센싱 / 소비 정서 / 온디바이스 에이전트
3. 시스템 (0.75p): 파이프라인 그림 1장
4. 실험 (1.5p): S1 표, S2 그림, S3 표
5. 논의·한계·향후 (0.5p): 개입 효과 검증 설계(무작위 타이밍 대조군 포함), 프라이버시·규제
6. 참고문헌 (0.25p)
