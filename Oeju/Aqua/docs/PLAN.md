# 코엑스 아쿠아리움 어종 도감 — 작전 문서 (v0.1)

## 한 줄 정의
수조 앞에서 폰 카메라를 들면 물고기를 실시간으로 잡아내고, 잠깐 조준을 유지하면 "포획"되어 내 도감에 카드로 쌓이는 웹앱(PWA).
입장 QR로 바로 열리게 해서 설치 장벽을 없앤다.

## 핵심 경험 루프
1. **탐사(스캔)** — 카메라 화면에 인식된 생물마다 조준 브래킷 + 이름 표시
2. **조준 유지** — 같은 어종이 연속으로 잡히면 링이 차오름 (게임 장치이자 오인식 필터)
3. **포획** — 버튼을 누르면 그 순간 사진이 잘려 카드로 저장, 경험치 획득
4. **도감** — 구역별 수집률, 잠긴 칸은 실루엣, 카드에는 내가 찍은 사진 + 생태 정보
5. **오늘의 탐사** — 날짜별로 바뀌는 목표 3종 (재방문·동선 유도)

## 인식 엔진 설계 (로보플로우 중심)

```
[폰 카메라] --(약 2~4fps, 640px JPEG)--> [/api/detect (우리 서버)] --> [Roboflow Serverless V2]
     ^                                        |  API 키는 서버에만
     |                                        v
[오버레이 + 조준 추적기] <---- 정규화된 박스(0~1) + 도감 매핑 결과
```

- **서버 프록시**: 키 노출 방지, 모델 교체를 환경변수로만 처리 (`ROBOFLOW_MODEL_ID`).
- **동시 요청 1개 원칙**: 응답이 와야 다음 프레임을 보낸다 → 네트워크가 느리면 자동으로 fps가 내려감.
- **클래스 매핑 층** (`src/lib/detection/classMap.ts`): 로보플로우 모델의 클래스명은 우리 도감 ID와 다르다.
  - 종 단위 클래스(`clownfish`, `Amphiprion ocellaris`) → 도감 종으로 직접 매핑
  - 무리 단위 클래스(`shark`, `jellyfish`, `ray`) → **무리(group)** 로 매핑. 포획 후 "어떤 상어였나요?" 후보에서 직접 고르게 하고 `self` 검증으로 기록
  - 매핑 없음 → "미등록 생물"로 표시만 하고 포획 불가
- **시간 투표(조준 유지)**: 프레임 단위 결과는 흔들린다. 같은 라벨이 3회 연속(빈 프레임 1회는 봐줌) + 평균 신뢰도 0.5 이상일 때만 포획 가능.
- **데모 모드**: 키가 없으면 서버가 가짜 탐지를 돌려준다. 화면에 "데모 모드"를 항상 표시.

### 로보플로우 모델 선택 기준 (현장 전 체크)
| 항목 | 기준 |
|---|---|
| 클래스 | 코엑스 전시종과 겹치는 종 단위 클래스가 많을수록 좋음. 무리 단위만 있어도 동작은 함 |
| 수조 환경 | 유리 반사·푸른 조명·저조도 학습 데이터가 있는지 |
| 속도 | Serverless 왕복 300~800ms 목표. 넘으면 아래 2단계 고려 |

### 단계별 진화
- **1단계 (지금)**: Universe 공개 모델 + 클래스 매핑 + 무리 단위 자가 라벨링
- **2단계**: 포획 시 저장된 사진(사용자 동의)을 로보플로우 프로젝트로 업로드 → 코엑스 전용 모델 학습 (데이터 플라이휠)
- **3단계**: `inferencejs`로 브라우저 온디바이스 추론 → 진짜 실시간(15fps+), 서버 비용 0. 서버 프록시는 fallback으로 유지

## 리스크
- **전시종 목록 미확정**: `src/data/species.ts`는 초안이다. 현장/공식 안내로 검증 전엔 `verified: false`.
- **수조 유리 반사·저조도**: 공개 모델 정확도가 낮을 수 있음 → 시간 투표 + 무리 단위 fallback으로 완화, 2단계 학습이 근본 해결.
- **관람 동선 방해**: 폰을 오래 들게 하지 않도록 조준 유지 시간을 1~2초로 제한.
- **API 비용**: 2~4fps × 관람객 수. 3단계 온디바이스 전환이 비용 해법.

## 화면
- `/` 홈: 레벨·경험치, 수집률, 오늘의 탐사, 탐사 시작
- `/scan` 탐사: 카메라 + 조준 HUD + 포획 결과 시트
- `/dex` 도감: 구역 필터, 잠금 실루엣
- `/dex/[id]` 상세: 내 사진, 생태 정보, 관찰 팁

## 저장
MVP는 로그인 없이 기기 로컬(localStorage). 사진은 192px 썸네일만 저장.
