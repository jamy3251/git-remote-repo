# Listen Together

게임하며 둘이, 끊김 없이, 같은 노래를 같은 순간에.

유튜브 재생목록을 입력하면 방에 모인 사람들이 **같은 곡을 싱크 맞춰 동시에** 듣는다.
디스코드 음악봇처럼 한 서버가 오디오를 스트리밍하는 게 아니라, **각자 브라우저가
유튜브에서 직접 재생하고 서버는 "지금 몇 초/재생·정지/곡 인덱스" 상태만 동기화**한다.
그래서 유튜브 throttle로 인한 끊김이 구조적으로 없다.

## 빠른 시작

```bash
npm install
npm start
# http://localhost:3000
```

1. 이름 입력 → "새 방 만들기" → "참여"
2. 방의 "링크 복사"로 친구에게 링크 전달
3. 둘 다 "▶ 탭하여 같이 듣기 시작" 누르기 (브라우저 자동재생 정책 때문)
4. 방장이 유튜브 재생목록/영상 URL 붙여넣고 "불러오기"
5. 같이 듣기 시작. 방장의 재생/정지/이전/다음이 모두에게 동기화됨.

## 동작 원리

- **호스트 권위형 싱크**: 한 명(방장)이 조종한다. 방장의 로컬 플레이어가 진실의 원천.
- 서버는 `{playlist, index, isPlaying, position, updatedAt}`를 룸 상태로 보유하고
  방장의 control 이벤트와 1초 heartbeat를 게스트에게 중계.
- 게스트는 받은 상태로 자기 플레이어를 보정한다. 오차 1초 초과 시 `seekTo`.
- "내가 조종하기"로 누구든 방장이 될 수 있다(권한 이전).

## 스택

- 서버: Node + Express + Socket.IO (단일 인스턴스, 인메모리 룸)
- 클라이언트: 정적 HTML/JS + YouTube IFrame Player API

## 알려진 제약 (v1)

- 일부 영상은 유튜브 정책상 임베드 불가 → 재생 안 될 수 있음.
- 모바일 브라우저 자동재생 제약 → 시작 게이트(탭) 필요.
- 서버 재시작 시 방 상태 소멸(인메모리).
